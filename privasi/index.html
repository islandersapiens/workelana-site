Kebijakan Privasi

Berlaku sejak 15 November 2026, diperbarui 27 November 2026

Workelana adalah komunitas independen untuk orang Indonesia yang mencari kerja remote. Halaman ini menjelaskan data apa yang diproses saat kamu memakai situs ini dan bergabung di server Discord kami.

Situs web ini

  • Situs ini tidak memiliki formulir dan tidak meminta data pribadimu secara langsung.
  • Penyedia hosting dapat mencatat data teknis standar, seperti alamat IP dan jenis peramban, untuk keamanan dan kinerja.
  • Semua huruf (font), gambar, dan kode situs ini disajikan dari server kami sendiri. Situs ini tidak memuat layanan pihak ketiga seperti Google Fonts atau alat analitik.

Discord

Saat kamu bergabung, Discord memproses datamu (misalnya nama pengguna dan pesan) sesuai kebijakan privasi Discord. Kami sebagai pengelola server dapat melihat pesan di channel server dan informasi akun yang tampil di Discord. Kami tidak menjual data anggota kepada pihak lain.

Link referral

Sebagian link loker yang dibagikan admin adalah link referral. Jika kamu mendaftar lewat link itu, platform tujuan memproses datamu sesuai kebijakannya sendiri, dan Workelana dapat menerima bonus dari platform tersebut tanpa biaya tambahan untukmu. Link referral selalu diberi tanda.

Hakmu

Kamu dapat meminta kami menghapus pesanmu di server atau mempertanyakan data yang kami pegang tentangmu. Hubungi kami lewat Discord. Untuk data di Discord atau di platform tujuan, kamu juga perlu menghubungi mereka.

Perubahan

Kebijakan ini dapat berubah. Tanggal berlaku di atas akan diperbarui ketika itu terjadi.

Dokumen ini ringkas dan bukan nasihat hukum. Sesuaikan jika Workelana mulai mengumpulkan data lewat formulir, email, atau pembayaran.

Workelana adalah komunitas independen, bukan mitra resmi platform mana pun yang disebutkan. Sebagian link loker di komunitas adalah link referral dan akan diberi tanda.
